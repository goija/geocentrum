# WCAG 2.2 Toegankelijkheidsverklaring

VORTEX OS interfaces (`cockpittools/`) voldoen aan de volgende criteria:
* **Contrast:** Minimaal 4.5:1 voor tekst en interactieve elementen.
* **Toetsenbord:** Alle viewports zijn volledig navigeerbaar zonder muis.
* **Semantiek:** Correct gebruik van HTML5 tags voor screenreaders.
